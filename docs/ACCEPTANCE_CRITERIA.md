# 현재 검수 기준

현재 업무 규칙은 [현재 운영 기준](CURRENT_OPERATING_BASELINE.md)을 따른다. 기본 업무 69항목과 AI 23항목의 ID는 유지하며, 문구와 실행 테스트 연결은 `tests/acceptance_basic.json`, `tests/acceptance_ai.json`과 대조한다. 이 목록 자체는 통과 결과가 아니다.

AI 검증의 사실성·보안 범위는 모의 응답과 지정된 근거 사례다. 실제 모델 품질·운영 HTTPS·외부 백업·운영 서버 성능은 별도로 확인한다.

## 실행과 결과

[README의 격리 검수 절차](../README.md#격리-검수-시작)로 테스트를 실행한다. 각 실행의 `results.json`과 경계 검사 `boundary.json`을 명시적으로 전달한다. 서로 다른 소스·과거 실행 결과를 합쳐 현재 전체 통과로 표시하지 않는다.

```sh
.venv/bin/python scripts/verify_acceptance.py \
  --results .local/verification-runs/<실행ID>/results.json \
  --suite all --boundary .local/verification-runs/<경계실행ID>/boundary.json
```

결과는 입력 결과 파일 옆의 `acceptance.json`·`acceptance.md`에 새로 생성한다. 기존 결과는 덮어쓰지 않는다. 누락·실패·skip·소스 변경·미실행 Docker 검사는 통과로 세지 않는다.
