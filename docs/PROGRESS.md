## 4. 미완료·준비사항

- 앱 전체와 데이터 모델·로그인·기본 고객관리·AI 기능은 미구현이다.
- Python 3.13 전용 환경과 잠금 의존성, Docker/Compose, 개발/테스트 PostgreSQL DB를 준비해야 한다. 현재 기존 코드 보완이 아닌 신규 프로젝트 대상이다.
- ignore 규칙·빈 .env.ai.example·서버 전용 로더는 P1에 구현한다. 현재 설정 파일을 만들거나 기존 파일을 병합한 상태가 아니다.
- 실제 AI 키·공급자·모델·단가는 없다. 이는 기본 업무/테스트 구현을 막지 않으며 유료 호출을 활성화하지 않는다.
- 실제 Git 추적 상태·이미지 레이어·브라우저·로그 유출 검사는 관련 구현 후 수행한다. 계획과 임시 검사만으로 검증 완료를 선언하지 않는다.
- 현 단계 또는 첫 기반 구현을 막아 사용자 확인이 필요한 업무 충돌은 발견하지 못했다. 이후 구현 세부값과 문구 교차 지점은 계획서에 기록한다.
