## 직접 확인과 범위 제한

1. README1절대로 DB→migrate→collectstatic→Gunicorn, 별도 terminal scheduler를 시작한다. 기존 가짜 관리자 계정을 사용하며 이미 변경한 비밀번호는 유지했다.
2. **DB 분배·회수**에서 현장→확인→전체 팀원/직원→직원당 소량→분배를 확인한다. 충분치 않으면0건과 가능 수량이 나온다.
3. **DB 관리**에서 담당/할당일·담당 변경·동일인 no-op·미할당 회수·상담 보존을 확인한다. 상담 편집 중 변경 버튼을 누르면 선행 저장/머무르기/폐기를 선택한다.
4. **오늘 할당 회수** 확인 모달에서 진행 포함 규칙·실제 결과를 확인한다.
