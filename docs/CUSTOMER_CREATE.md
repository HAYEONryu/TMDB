# DB 관리에서 고객 단건 추가

팀장(ADMIN)의 DB 관리에서 현장을 선택하고 **행 추가**를 누르면 표 맨 위에 새 입력 행이 생깁니다. 고객명은 선택, 연락처는 필수입니다. 기존 표와 같은 상담 항목을 입력하고 **저장**을 누르면 선택한 현장에 미할당 고객으로 등록됩니다. 입력 중에는 한 행만 추가할 수 있고 **추가 취소**로 버릴 수 있습니다. 직원 화면과 휴지통에서는 제공하지 않습니다.

기존 검색·상세 필터·정렬은 유지합니다. 등록한 고객이 현재 조건에 맞지 않으면 조회 목록에 나타나지 않으며 저장 안내에 이를 표시합니다. 신규 행과 기존 수정 행은 미저장 행 수 및 화면 이동·검색·필터 변경 보호에 함께 포함됩니다. 연락처는 기존 규칙대로 010으로 시작하는 11자리로 정규화하고, 전체 현장의 휴지통 제외 고객 중 중복을 거절합니다.

`POST /api/customers/create`는 ADMIN 및 현재 계정 확인 후 기존 업무 트랜잭션 잠금으로 현장을 재확인합니다. 허용된 편집 필드만 받으며 고객·초기 재콜·추가 작업 이력·7일 요청 영수증을 한 트랜잭션으로 저장합니다. 추가 자체는 상담 저장 실적으로 집계하지 않습니다. 응답 유실 시 같은 요청 키와 본문으로 재시도해 중복 생성을 막습니다. 불확실한 요청의 새 행은 결과 확인 전까지 편집을 막고, 새로고침·화면 이동 시 미저장 보호를 유지합니다. 입력 내용은 브라우저 저장소에 보관하지 않습니다.
